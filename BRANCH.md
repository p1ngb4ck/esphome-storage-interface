# `pr/web-server-file-api`

One part of the topic repo p1ngb4ck/esphome-storage-interface. The whole topic, with its description, is the branch `main`.

Change of this branch: `web_server`: `file_api`, `raw_api`, `file_browser` (`simple`, or `advanced` with js-fileexplorer)

Based on these branches, whose changes it holds and builds on:

- `pr/storage`: the `storage` component: registry, path / filesystem / network / raw storages, the asynchronous worker (jobs, streams), `storage.*` actions, PSRAM transfer buffer, change feed, ISO 9660 mount
- `pr/web-server-idf-file-uploads`: `web_server_idf`: multipart uploads for the file API, async uploads per handler, an explicit empty file created
